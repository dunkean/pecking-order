# Provenance

## Design source / Source de conception

The user-owned `ttrpg_content_generator/worldbuilder_social_engine_study.md` was read as the starting brief and archived unchanged under `docs/reference/`. Pecking Order implements the institutional reference layer, not the entire social simulation described there.
Le document de l’utilisateur a servi de cadre et est archivé sans modification. Le projet réalise le référentiel institutionnel, pas la simulation sociale complète.

## Authored data / Données éditoriales

Generic templates, translations, explanatory text and code were authored for this project with AI assistance. They are not a scraped historical dataset. Runtime resolution uses no LLM.
Les modèles, traductions, explications et le code ont été créés pour ce projet avec une assistance IA. La résolution n’utilise aucun LLM. Les formes d’origine sont préservées quand elles sont renseignées ; leur traduction n’établit pas une équivalence de rang.

A source supports only the explicitly scoped claim. Blueprint-level `source_supported` means that a cultural binding exists; generic offices and powers remain independently labelled. Source references and short titles are distributed, not downloaded source texts.
